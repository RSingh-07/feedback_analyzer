# Food Delivery Review Analyzer

A small review-analysis project with a FastAPI service, a Streamlit interface, and a SQLite database. It analyzes food-delivery reviews for sentiment, score, and main theme. The Streamlit app accepts multiple reviews pasted one per line.

## Features

- Classifies each review as `positive`, `negative`, or `neutral`.
- Assigns an integer score from 1 (very bad) to 5 (very good).
- Identifies a one-word topic such as `delivery`, `quality`, `taste`, or `price`.
- Displays a results table and a batch summary with review count, average score, and percentage of positive reviews.
- Lets you explicitly save analyzed reviews to SQLite and view saved records in the app.
- Includes [sample_reviews.txt](./sample_reviews.txt) with example reviews.

## Project files

| File | Purpose |
| --- | --- |
| `api.py` | FastAPI endpoint that asks the Gemini API to analyze one review. |
| `app.py` | Streamlit UI that analyzes one or more reviews, summarizes results, and manages display/save actions. |
| `database.py` | Creates and reads/writes the SQLite feedback table. |
| `feedback.db` | SQLite database file, created in the project directory when the app starts. |
| `sample_reviews.txt` | Sample reviews; each non-empty line is a separate review. |

## Requirements

- Python 3.10 or newer
- A Google Gemini API key
- Python packages: `fastapi`, `uvicorn`, `google-genai`, `python-dotenv`, `pydantic`, `streamlit`, and `requests`

Install the packages if they are not already installed:

```bash
pip install fastapi uvicorn google-genai python-dotenv pydantic streamlit requests
```

## Configure the Gemini API key

Create a `.env` file in the project directory and add your key:

```env
GEMINI_API_KEY=your_api_key_here
```

Keep `.env` private and do not commit or share your API key.

## Run the project

Open two terminals in this directory.

In the first terminal, start the API:

```bash
uvicorn api:app --reload
```

In the second terminal, start the Streamlit app:

```bash
streamlit run app.py
```

Open the local URL printed by Streamlit in your browser. The API must be running while you analyze reviews. The app sends each review to `http://127.0.0.1:8000/analyze`.

## Use the app

1. Paste one review per line into the review box. Blank lines are ignored.
2. Select **Analyze reviews**. Each review is sent to the API separately.
3. Review the analysis table and batch summary.
4. Select **Save these results to the database** to store the displayed batch.
5. Select **View database records** to view saved feedback.

The results table contains:

| Column | Description |
| --- | --- |
| Review | Original review text |
| Label | Sentiment label (`positive`, `negative`, or `neutral`) |
| Score | Rating from 1 to 5 |
| Theme | Main topic identified by the analyzer |

The summary reports the number of successfully analyzed reviews, average score, and percentage labeled positive. If some reviews fail, successful results are still shown, and failures are reported by review number.

## API

`POST /analyze` accepts one review:

```json
{
  "text": "The food arrived hot and the delivery was quick."
}
```

It returns the analysis fields:

```json
{
  "label": "positive",
  "score": 5,
  "theme": "delivery"
}
```

The response is generated by the Gemini model configured in `api.py`.

## Database schema

The `feedback` table is initialized automatically and contains:

| Column | Type | Description |
| --- | --- | --- |
| `id` | Integer primary key | Unique row identifier |
| `review` | Text | Original review |
| `label` | Text | Sentiment label |
| `score` | Integer | Score from 1 to 5 |
| `theme` | Text | Main review topic |
